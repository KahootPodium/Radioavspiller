# Radioavspiller
Dette er en enkel C++ radioavspiller som spiller NRK radio via ffplay

## Hvordan kjøre
```bash
g++ main.cpp -o radio
./radio
```

## Funksjoner
- Spiller norske radiostasjoner online
- Enkel terminalbasert brukeropplevelse
- Bruker C++ og systemkommandoer for avspilling

## Teknologi
- C++
- ffmpeg
